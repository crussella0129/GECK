# Launch Prompt — My Project

Generated by GECK from `mission-spec.md`. Paste this into your agent session
to start Sprint 0 with full mission context.

## 1. Install / verify Sprint Loops

```
/plugin marketplace add crussella0129/sprint-loops
/plugin install sprint-loop@sprint-loops
```

**Windows note:** Sprint Loops' shell scripts need Git Bash or WSL. `geck`
itself is a native binary and needs neither.

## 2. Read the mission first

Read `mission-spec.md` in full before doing anything else. It is the
authoritative mission document — the drift baseline every sprint compares
against. Reference it; do not paraphrase it into the loop's ephemeral state.

## 3. Start Sprint 0

```
/sprint-loop start "Ship a REST API with auth, rate limiting, and OpenAPI docs — full mission in mission-spec.md"
```

## 4. Wire the mission into the loop

- **Seeds are already written.** `decisions.md` has ADR-000 pointing at
  `mission-spec.md`, `agent-tasks/agent-tasks.md` has the backlog seeds, and
  `confidence.txt` is at 1.0. Confirm them at Init rather than recreating
  them — Sprint Loops' own `init-sprint.sh` never overwrites existing files.
- **Establish the work branch** (`dev`) per the Working
  Agreement, and record the merge mode (`approve`) in
  `sprint-meta.md`.
- **Success criteria in `mission-spec.md` are mission-level**, not
  per-sprint. At each Loop Phase, check off any criterion this sprint
  completed.
- **Each Research Phase, re-read `mission-spec.md`** and report drift in the
  research report. ADR-000 makes this ride the existing decisions-reviewed
  gate, so `finalize-plan.sh` already enforces it — no extra step needed.

## 5. Run it unattended (optional)

Select **auto-accept ("auto mode")** at the Plan Phase's `ExitPlanMode`
prompt, then launch the whole loop under `/loop /sprint-loop continue`. The
stop criterion in SKILL.md still applies: visual/UX checks, irreversible or
undeterminable-consequence actions, genuine scope ambiguity, and unrecoverable
failures all halt for a human. Everything else proceeds.
